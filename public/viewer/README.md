# Expense policy

Expenses are **submitted in reports**, each with its receipts, and reviewed by a manager.

## What's covered

- Travel to and from a client's site
- Meals while travelling, up to 60.00 a day
- Lodging, when a visit runs overnight

## Steps

1. Add the expenses to a report.
2. Attach a receipt or an invoice to each one.
3. Submit the report. Your manager gets an email.

> A report returned for correction keeps its comment, so you can see what to change.

| Status | Meaning |
| --- | --- |
| Submitted | Waiting for the manager |
| Approved | Ready to be paid |
| Reimbursed | Paid |

See `expenses.csv` for the year so far, or the [Gears UI repository](https://github.com/TernaryTech-io/Gears.UI).
